# CACS-254: Scripting Language

**BCA 4th Semester — Lab Report**

---

## Introduction

This lab report covers the laboratory work for the Scripting Language course (CACS-254). It focuses on client-side scripting using JavaScript, DOM manipulation, event handling, form validation, browser storage, and interactive UI components. All exercises are implemented using HTML, CSS, and JavaScript without external frameworks.

---

## 📘 Lab Topic 1: JavaScript Fundamentals & DOM Manipulation

This topic introduces core JavaScript programming concepts as the foundation for dynamic web development. It covers:

- Functions and parameters
- String manipulation (sorting, counting, capitalization)
- Arrays (searching, sorting, joining)
- Loops and conditional statements
- Date and time operations
- JavaScript Objects and methods
- DOM selection and manipulation
- Event handling with buttons and forms
- Form validation using regular expressions
- Cookies and browser storage
- Interactive UI components (clocks, counters, calculators)
