## 📖 Overview

This repository contains the complete laboratory work for the **Scripting Language** course (CACS-254), taught in the 4th semester of BCA. The lab covers **JavaScript fundamentals, DOM manipulation, event handling, form validation, browser storage, and interactive UI components** in Lab 1, followed by **PHP server-side scripting, form handling, database integration, file operations, and security validation** in Lab 2. 

Lab 3 advances into **PHP Object-Oriented Programming (OOP), jQuery effects, AJAX for asynchronous data loading, and integration with Content Management Systems (CMS)**.

All lab questions are implemented as **self-contained files**, each with an interactive demo.

## 📘 Lab Topic 1: JavaScript Fundamentals & DOM Manipulation

This topic introduces the core JavaScript programming concepts that form the foundation for dynamic web development. It covers:

- ✅ Functions and parameters
- ✅ String manipulation (sorting, counting, capitalization)
- ✅ Arrays (searching, sorting, joining)
- ✅ Loops and conditional statements
- ✅ Date and time operations
- ✅ JavaScript Objects and methods
- ✅ DOM selection and manipulation
- ✅ Event handling with buttons and forms
- ✅ Form validation using regular expressions
- ✅ Cookies and browser storage
- ✅ Interactive UI components (clocks, counters, calculators)

---

## 📘 Lab Topic 2: PHP Fundamentals & Server-Side Scripting

This topic introduces the fundamentals of server-side scripting using PHP and MySQL. It covers:

- ✅ Variables, Data Types, and Constants
- ✅ Basic Math Operations and Geometry (Area, Simple Interest)
- ✅ User-Defined Functions and Parameters
- ✅ String Manipulation (slicing, capitalization, length)
- ✅ Array Operations (Associative & Multidimensional)
- ✅ Displaying Arrays in HTML Tables
- ✅ Conditional Statements and Loops
- ✅ HTML Forms and User Input Handling
- ✅ Form Validation using Regular Expressions (Regex)
- ✅ Sessions and Cookies for Login Systems
- ✅ File Handling Operations (Read, Write, Rename, Permissions)
- ✅ File Uploads (CV and Profile Image with Validation)
- ✅ Database Integration (MySQL Connection & Tables)
- ✅ CRUD Operations (Create, Read, Update, Delete)
- ✅ Dynamic CRUD for Multiple Tables (Courses & Students)
- ✅ Mark Sheet Generation and Storage in Database
- ✅ Post/Redirect/Get (PRG) Pattern for Data Integrity
- ✅ Server-Side Email Notification

- ✅ Inheritance and Method Overriding
- ✅ Interfaces and Polymorphism
- ✅ Access Modifiers (Public, Private, Protected)
- ✅ Constructor Validation and Type Checking
- ✅ jQuery Effects (Hide, Show, Fade, Slide, Animate)
- ✅ Client-side Form Validation using jQuery
- ✅ AJAX Form Submission (Login System)
- ✅ Asynchronous Data Loading using XMLHttpRequest
- ✅ Fetching JSON Data from an API / Local File
- ✅ AJAX Dynamic Dropdown (Country and City)
- ✅ Database Connectivity via AJAX (Username Check)
- ✅ CMS Installation (WordPress and Joomla)
- ✅ Creating Posts and Pages in CMS
- ✅ Creating and Managing Menus in CMS
- ✅ Building a Blog Website using CMS
